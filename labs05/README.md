# Лабораторная работа 5. Обработка строк
---

## 1. normalize.py

### Логика
- `text.split()` без аргумента разбивает по любым пробельным символам
  и отбрасывает пустые части.
- `" ".join(...)` соединяет слова через один пробел.
- Регистр сохраняется — `lower()` не вызывается.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `  Один   два  ` | `Один два`, слов 2, длина 8 | совпало |
| пустая строка | длина 0, слов 0 | совпало |
| `a  b  c` | `a b c`, слов 3 | совпало |
| только пробелы | длина 0, слов 0 | совпало |

## 2. palindrome.py

### Логика
- `text.replace(" ", "").lower()` — очистка.
- `cleaned == cleaned[::-1]` — проверка через срез-переворот.
- Пустая очищенная строка — отдельный случай.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `А роза упала на лапу Азора` | Палиндром | совпало |
| `а     ` | Палиндром | совпало |
| только пробелы | Нет текста | совпало |
| `Python` | Не палиндром | совпало |
| `А!` | Не палиндром | совпало |
| `шалаш` | Палиндром | совпало |

## 3. replace.py

### Логика
- `text.count(":")` — число вхождений.
- `text.replace(":", "-")` — замена всех вхождений.
- Порядок: сначала `count`, потом `replace`.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `a::b:` | Замен 3, `a--b-` | совпало |
| `abc` | Замен 0, `abc` | совпало |
| `::::` | Замен 4, `----` | совпало |
| пустая | Замен 0, пусто | совпало |

## 4. variant.py — Вариант 14: слова с чётной длиной

### Логика
- `word.strip(".,!?;:")` — убирает указанные символы только по краям.
- `len(cleaned) % 2 == 0` — чётная длина.
- `continue` — пропуск пустых после очистки.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `Анна, армия! Я читаю. Книга, край, рама..` | анна, край, рама; количество 3 | совпало |
| пустая | Нет совпадений, количество 0 | совпало |
| `!!!` | Нет совпадений, количество 0 | совпало |
| `дом окно` | окно; количество 1 | совпало |
| `а б в г` | количество 0 | совпало |
