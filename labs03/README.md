## 1. minimum.py

### Логика
- Если `a <= b` и `a <= c` → минимум `a`.
- Иначе если `b <= a` и `b <= c` → минимум `b`.
- Иначе → минимум `c`.

Используется `<=`, а не `<`, чтобы корректно работали равные числа.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| 2, 10, 3 | 2 |совпало |
| 5, 5, 5 | 5 | совпало|
| −4, 0, −2 | −4 | совпало|
| 10, 3, 2 | 2 (минимум на последней позиции) |совпало |
| 5, 5, 7 | 5 (два равных минимума) | совпало|

## 2. calculator.py

### Логика
- Цепочка `if/elif/elif/elif/else` по операции.
- Для `/` — вложенная проверка `b == 0`.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| 7, /, 2 | 3.50 |совпало |
| 5, /, 0 | Деление на ноль запрещено | совпало|
| 5, ?, 2 | Неизвестная операция |совпало |
| 3, +, 4 | 7.00 |совпало |
| 10, -, 4 | 6.00 | совпало|
| 3, *, 4 | 12.00 | совпало|
| −7, /, 2 | −3.50 |совпало |

## 4. variant.py — Вариант 14: наличие товара от плана

### Логика
- Сначала проверка диапазона: `value < 0 or value > 100`.
- Затем цепочка `elif` по порогам. Порядок важен: первая подходящая ветвь
  выполняется, остальные пропускаются.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| −1 | Ошибка диапазона |совпало |
| 0 | Малый запас | совпало|
| 100 | Большой запас |совпало |
| 101 | Ошибка диапазона | совпало|
| 19 | Малый запас |совпало |
| 20 | Средний запас | совпало|
| 64 | Средний запас | совпало|
| 65 | Большой запас | совпало|
