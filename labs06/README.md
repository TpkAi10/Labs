# Лабораторная работа 6. Списки и обработка наборов данных
---

## 1. statistics.py

### Логика
- `line.split()` разбивает по пробелам, `int()` и `append()` строят список.
- Пустая строка → пустой список → ветвь «Нет данных».
- Для пустого списка **не** вызываются `min()`, `max()`, нет деления на ноль.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `-2 0 5 3` | 4, 6, −2, 5, 1.50 | совпало |
| `8` | 1, 8, 8, 8, 8.00 | совпало |
| пустая | Нет данных | совпало |
| `5 5 5` | 3, 15, 5, 5, 5.00 | совпало |

## 2. transform.py

### Логика
- Для отрицательных: `-number`. Для остальных: как есть.
- `numbers` не изменяется.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `-2 0 5 -2` | Новый `[2, 0, 5, 2]`, исходный `[-2, 0, 5, -2]` | совпало |
| пустая | Оба `[]` | совпало |
| `1 2 3` | Оба `[1, 2, 3]` | совпало |
| `-5` | Новый `[5]`, исходный `[-5]` | совпало |

## 3. positions.py

### Логика
- `max(numbers)` — максимум.
- `enumerate(numbers)` — пары «индекс, значение».
- Совпадающие с максимумом индексы добавляются в `positions`.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `3 7 2 7` | Максимум 7, индексы `[1, 3]` | совпало |
| `7 7` | Максимум 7, индексы `[0, 1]` | совпало |
| `-3 -1 -2` | Максимум −1, индексы `[1]` | совпало |
| пустая | Нет данных | совпало |
| `5` | Максимум 5, индексы `[0]` | совпало |

## 4. variant.py — Вариант 14: числа, кратные 5

### Логика
- `number % 5 == 0` — кратность. Ноль подходит.
- `sorted(selected)` — новая сортированная копия, сам `selected` не меняется.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| `-8 -3 0 6 6 1` | `[0]`, 1, 0, `[0]` | совпало |
| пустая | `[]`, 0, 0, `[]` | совпало |
| `5 10 15 20` | `[5, 10, 15, 20]`, 4, 50, `[5, 10, 15, 20]` | совпало |
| `1 2 3` | `[]`, 0, 0, `[]` | совпало |
| `20 5 10 5` | `[20, 5, 10, 5]`, 4, 40, `[5, 5, 10, 20]` | совпало |
