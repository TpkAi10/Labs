# Лабораторная работа 10. Текстовые файлы и обработка ошибок

---

## 1. Формат matrix.txt

    Первая строка: rows cols — два положительных целых числа.
    Далее ровно rows строк, в каждой ровно cols целых чисел.
    Лишние и пустые строки — ошибка.
    Один обычный перевод строки после последней строки данных допустим.

Пример:

    2 3
    1 -2 3
    4 0 -6

## 2. files_lab.py

### read_matrix(path)

Читает файл UTF-8. Возвращает список строк. При ошибке формата
бросает `ValueError` с понятным пояснением и номером строки.

Проверяет:
- файл не пуст,
- заголовок — ровно два целых положительных числа,
- количество строк данных совпадает с заголовком,
- в каждой строке ровно `cols` целых чисел.

### selected_sum(matrix) — вариант 14

Сумма положительных элементов с нечётным индексом столбца.
Индексы с нуля. Если подходящих нет — 0.

### Проверки

| Вызов | Ожидание |
|---|---|
| `read_matrix` на `1 2\n7 -1\n` | `[[7, -1]]` |
| `read_matrix` на `1 1\n0\n` | `[[0]]` |
| `read_matrix` на пустом файле | `ValueError` |
| `read_matrix` на `0 3\n` | `ValueError` |
| `read_matrix` на `1 2\n1\n` | `ValueError` (строка 2) |
| `read_matrix` на `1 2\n1 x\n` | `ValueError` (строка 2) |
| `read_matrix` на `1 1\n7\n8\n` | `ValueError` |
| `read_matrix` на отсутствующем пути | `FileNotFoundError` |
| `read_matrix` на `1 2\n7 -1\n\n` | `[[7, -1]]` (лишний перевод допустим) |

## 3. main.py

### read_positive_integer()

Повторяет ввод, пока не получено целое > 0. Различает:
- «Это не целое число» — при `ValueError` от `int()`,
- «Число должно быть больше нуля» — при `<= 0`.

### main()

1. Читает `matrix.txt` через `read_matrix`.
2. Ловит:
   - `FileNotFoundError` — файла нет,
   - `UnicodeError` — не UTF-8,
   - `OSError` — проблемы доступа,
   - `ValueError` — неверный формат.
3. При любой ошибке выходит, **не трогая** `report.txt`.
4. Только после успешной проверки пишет отчёт.

### Пример отчёта

    Суммы строк: 2 -2
    Суммы столбцов: 5 -2 -3
    Результат варианта: 0

## 4. test_files.py

Содержит проверки через `TemporaryDirectory()`. При успехе —
`Все проверки пройдены`.

Проверяется:
- обычное чтение,
- 1×1,
- пустой файл,
- заголовок `0 3`,
- недостаточное/лишнее число строк,
- нечисловая ячейка,
- отсутствующий файл,
- `selected_sum` на разных матрицах,
- допустимость одного перевода строки после данных.

---

## 5. Сохранность старого отчёта при ошибке

Проверено вручную: при некорректном `matrix.txt` (например, `0 3`)
`main.py` выводит сообщение об ошибке, а `report.txt` остаётся прежним.
Это потому, что запись отчёта идёт **после** успешной проверки всех данных.
