## 4. debug.py

### Разбор ошибок

**Фрагмент А.** `"2"` и `"3"` — строки, `+` соединяет их в `"23"`. Исправление: `int()` → `5`. Типы: до — `str`, после — `int`.

**Фрагмент Б.** `input()` возвращает строку, `строка + 1` даёт `TypeError`. Исправление: `int(input(...))` → при вводе `17` получаем `18`. Типы: до — `str`, после — `int`.

**Фрагмент В.** `first + second + third / 3` сначала делит, потом складывает → `14.333...`. Исправление: скобки `(first + second + third) / 3` → `7.0`.

### Проверки

| Проверка | Вход | Ожидание | Факт |
|---|---|---|---|
| А, обычная | "2" + "3" | 5 | совпало |
| А, дополнительно | "10" + "15" | 25 | совпало |
| Б, обычная | 17 | 18 | совпало |
| Б, дополнительно | 25 | 26 | совпало |
| В, обычная | 4, 7, 10 | 7.0 | совпало |
| В, дополнительно | 10, 20, 30 | 20.0 | совпало |

## 6. variant.py — Вариант 14. Магазин для животных

Позиции: Упаковки корма, Игрушки.

### Ограничения из условия
- Количество — целое неотрицательное.
- Цены — неотрицательные дробные.
- Доставка — неотрицательна.
- Скидка — от 0 до 100.
- Внесённой суммы достаточно для оплаты.

### Проверки

| Проверка | Вход | Ожидание (вручную) | Факт |
|---|---|---|---|
| Обычная | 3×12.50, 2×20.00, доставка 10.00, скидка 0, внесено 100.00 | 37.50; 40.00; 77.50; 87.50; 5; 12.50 | совпало |
| Со скидкой | то же, скидка 10% | 7.75; итого 79.75; сдача 20.25 | совпало |
| Граничная: нулевое количество | qty1 = 0 | стоимость 0.00; товары 40.00; итого 50.00; кол-во 2; сдача 10.00 | совпало |
| Граничная: нулевая доставка | доставка 0 | итого 77.50 | совпало |
| Граничная: точная оплата | внесено 87.50 | сдача 0.00 | совпало |
| Особая: названия из нескольких слов | «Сухой корм для кошек», «Мячик с колокольчиком» | названия выводятся целиком | совпало |

### Пример расчёта вручную (обычная проверка)

- Первая позиция: 3 × 12.50 = 37.50
- Вторая позиция: 2 × 20.00 = 40.00
- Товары без доставки: 37.50 + 40.00 = 77.50
- Скидка 0%: 0.00
- Товары со скидкой: 77.50
- Доставка: 10.00
- Итого с доставкой: 87.50
- Общее количество: 5
- Внесено: 100.00
- Сдача: 12.50

### Пример расчёта вручную (со скидкой 10%)

- Товары без доставки: 77.50
- Скидка: 77.50 × 10 / 100 = 7.75
- Товары со скидкой: 69.75
- Доставка: 10.00
- Итого с доставкой: 79.75
- Сдача при 100.00: 20.25
