## 1. table.py

### Функции

- `row_sums(matrix)` — список сумм строк. Для `[]` → `[]`.
- `column_sums(matrix)` — список сумм столбцов. Для `[]` → `[]`.
- `diagonal_pattern(size)` — квадрат `size×size`: диагональ 0, выше 1, ниже 2.
- `transform(matrix)` — вариант 14: элементы от −2 до 3 включительно возвести
  в квадрат. Возвращает новую матрицу, исходная не меняется.

### Проверки

| Вызов | Ожидание |
|---|---|
| `row_sums([[1,2,3],[4,5,6]])` | `[6, 15]` |
| `column_sums([[1,2,3],[4,5,6]])` | `[5, 7, 9]` |
| `row_sums([[7]])` | `[7]` |
| `column_sums([[7]])` | `[7]` |
| `row_sums([[1],[-1],[0]])` | `[1, -1, 0]` |
| `column_sums([[1],[-1],[0]])` | `[0]` |
| `row_sums([])` | `[]` |
| `column_sums([])` | `[]` |
| `diagonal_pattern(1)` | `[[0]]` |
| `diagonal_pattern(3)` | `[[0,1,1],[2,0,1],[2,2,0]]` |
| `transform([[-2,0,3],[4,-5,6]])` | `[[4,0,9],[4,-5,6]]` |
| `transform([])` | `[]` |
| `transform([[-1,1,2]])` | `[[1,1,4]]` |
| `transform([[-3,4]])` | `[[-3,4]]` |
| `transform([[-2]])` | `[[4]]` |
| `transform([[3]])` | `[[9]]` |

## 4. Вариант 14 — элементы от −2 до 3 возвести в квадрат

### Контрольная матрица

    [[-2, 0, 3], [4, -5, 6]]

Результат:

    [[4, 0, 9], [4, -5, 6]]

Проверка:
- −2 → 4 (граница включена)
- 0 → 0
- 3 → 9 (граница включена)
- 4 → 4 (вне диапазона, не трогаем)
- −5 → −5 (вне диапазона)
- 6 → 6 (вне диапазона)
