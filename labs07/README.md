## 1. functions.py

### Функции

- `sum_digits(number)` — сумма цифр модуля числа. Для нуля — 0.
  Используется `abs()`, цикл `while` и целочисленная арифметика.
- `average(numbers)` — среднее списка или `None` для пустого.
  Исходный список не изменяется.
- `normalize_text(text)` — нижний регистр, без пробелов по краям,
  один пробел между словами.
- `select_numbers(numbers, threshold)` — вариант 14: числа, кратные
  `threshold + 1`. Порядок и повторы сохраняются, исходный список не меняется.

### Проверки (в test_functions.py)

| Вызов | Ожидание |
|---|---|
| `sum_digits(0)` | 0 |
| `sum_digits(507)` | 12 |
| `sum_digits(-507)` | 12 |
| `average([])` | None |
| `average([2, 4, 6])` | 4 |
| `normalize_text("  ПРИВЕТ   Мир  ")` | `"привет мир"` |
| `normalize_text("   ")` | `""` |
| `select_numbers([-5, 0, 2, 5], 2)` | `[0]` |
| `select_numbers([], 2)` | `[]` |
| `select_numbers([1, 2, 4, 5], 2)` | `[]` |
| `select_numbers([3, 6, 9, -3], 2)` | `[3, 6, 9, -3]` |
| `select_numbers([1, 2, 3], 0)` | `[1, 2, 3]` |
| `select_numbers([3, 3, 6], 2)` | `[3, 3, 6]` |
| `select_numbers([0, 1, 2], 2)` | `[0]` |

## 2. main.py

### Логика
- Импорт функций из `functions`.
- Код в `if __name__ == "__main__": main()` — при импорте не выполняется.
- Для пустого списка среднее выводится как «Нет данных».

## 3. test_functions.py

### Что делает
Содержит набор `assert`-проверок для всех функций. При истинном условии
ничего не выводит, при ложном — `AssertionError`.

### Как запустить

    python test_functions.py

При успехе выводится `Базовые проверки пройдены`.

### Намеренная ошибка (для защиты)

Если заменить в `select_numbers` условие
`if number % (threshold + 1) == 0:` на
`if number % (threshold + 1) != 0:`,
запуск `test_functions.py` завершится `AssertionError` на первой же
проверке варианта. Это демонстрирует, что проверки действительно работают.

После демонстрации ошибка возвращается к правильной версии.
