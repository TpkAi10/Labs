## 3. Предскажите результат

### Прогнозы до запуска

| Выражение | Мой прогноз | Результат Python | Совпало? |
|---|---|---|---|
| `2 + 3 * 4` | 14 | 14 | да |
| `(2 + 3) * 4` | 20 | 20 | да |
| `17 // 5` | 3 | 3 | да |
| `17 % 5` | 2 | 2 | да |
| `-7 // 2` | −4 | −4 | да |

### Объяснение

- `2 + 3 * 4` = 14: сначала умножение, потом сложение.
- `(2 + 3) * 4` = 20: скобки меняют порядок вычислений.
- `17 // 5` = 3: целая часть от деления.
- `17 % 5` = 2: остаток.
- `-7 // 2` = −4: оператор `//` округляет **вниз**, а не к нулю. Поэтому
  получается −4, а не −3.

Проверка равенства `a == (a // b) * b + a % b` для `a = -7, b = 2`:
`-7 == -4 * 2 + 1` → `-7 == -7` — верно.

## 4. variant.py — Вариант 14: плитки и упаковки

### Формулы
- Полных упаковок: `total // capacity`
- Остаток: `total % capacity`
- Всего упаковок: `(total + capacity - 1) // capacity`

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| 0, 10 | Полных 0, остаток 0, всего 0 | совпало|
| 20, 10 | Полных 2, остаток 0, всего 2 |совпало |
| 21, 10 | Полных 2, остаток 1, всего 3 | совпало|
| 1, 10 | Полных 0, остаток 1, всего 1 |совпало |
| 9, 10 | Полных 0, остаток 9, всего 1 | совпало|
| 10, 10 | Полных 1, остаток 0, всего 1 | совпало|

### Особые проверки

| Вход | Ожидание | Факт |
|---|---|---|
| 10, 0 | сообщение об ошибке | совпало|
| −5, 10 | сообщение об ошибке | совпало|

### Объяснение формулы (total + capacity - 1) // capacity

Обычное деление `total / capacity` даёт дробное число. Чтобы получить
минимальное **целое** число упаковок, нужно округлить вверх. Приём:
прибавить `capacity - 1` и взять целочисленное деление вниз.

Пример: `total = 21`, `capacity = 10`.
- Без приёма: `21 // 10 = 2` — не хватает на третью упаковку, хотя
  1 плитка лишняя.
- С приёмом: `(21 + 9) // 10 = 30 // 10 = 3` — правильно.

При `total = 20` (ровно две упаковки):
- `(20 + 9) // 10 = 29 // 10 = 2` — лишней упаковки не появляется.

При `total = 0`:
- `(0 + 9) // 10 = 0` — ноль упаковок, как требует условие.
