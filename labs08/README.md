## 4. totals_by_category / titles_in_category

### Проверки

Записи:

    records = [
        {"title": "A", "category": "основное", "amount": 4},
        {"title": "B", "category": "дополнительное", "amount": 2},
        {"title": "C", "category": "основное", "amount": 3},
    ]

| Вызов | Ожидание | Факт |
|---|---|---|
| `totals_by_category(records)` | `{"основное": 7, "дополнительное": 2}` | совпало |
| `titles_in_category(records, "основное")` | `["A", "C"]` | совпало |
| `titles_in_category(records, "нет")` | `[]` | совпало |
| `totals_by_category([])` | `{}` | совпало |
| `titles_in_category([], "основное")` | `[]` | совпало |

Исходные записи после вызовов равны копии `[record.copy() for record in records]`.

## 5. Индивидуальный вариант №14 — План мероприятий

Поле `amount` — количество участников.

### Свой пример (не менее 5 записей, минимум одна категория повторяется)

    records = [
        {"title": "Лекция по Python", "category": "учебное", "amount": 40},
        {"title": "Хакатон", "category": "соревнование", "amount": 60},
        {"title": "Круглый стол", "category": "учебное", "amount": 15},
        {"title": "Олимпиада", "category": "соревнование", "amount": 25},
        {"title": "Экскурсия", "category": "досуг", "amount": 30},
        {"title": "Мастер-класс", "category": "учебное", "amount": 20},
    ]

Ожидаемая сводка по категориям:

| Категория | Сумма |
|---|---|
| досуг | 30 |
| соревнование | 85 |
| учебное | 75 |

Поиск:
- `учебное` → `["Лекция по Python", "Круглый стол", "Мастер-класс"]`
- `соревнование` → `["Хакатон", "Олимпиада"]`
- `нет такой` → `[]`
