---

## 1. range_numbers.py

### Логика
- `range(a, b + 1)` — возрастание, потому что `stop` в `range` не входит.
- `range(a, b - 1, -1)` — убывание с шагом `-1`.
- `a == b` — отдельная ветвь, выводим одно число.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| 2, 4 | 2, 3, 4 |совпало |
| 4, 2 | 4, 3, 2 |совпало |
| 3, 3 | 3 | совпало|
| −2, 2 | −2, −1, 0, 1, 2 | совпало|
| 5, 5 | 5 | совпало|

## 2. statistics.py

### Логика
- `total = 0` — накопитель.
- `positives = 0` — счётчик.
- `maximum = None` — инициализация, корректная для отрицательных чисел.
  При первом числе максимум устанавливается на него.
- Инициализация `maximum = 0` дала бы неверный ответ для всех отрицательных.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| n=3: −5, −2, −8 | Сумма −15, положительных 0, максимум −2 | совпало|
| n=1: 0 | Сумма 0, положительных 0, максимум 0 |совпало |
| n=5: 1, 2, 3, 4, 5 | Сумма 15, положительных 5, максимум 5 |совпало |
| n=4: 10, −3, 7, −1 | Сумма 13, положительных 2, максимум 10 | совпало|

## 3. positive_input.py

### Логика
- Сначала ввод один раз до цикла.
- `while value <= 0:` — цикл продолжается, пока значение не положительное.
- Счётчик `attempts` увеличивается на каждой отклонённой попытке.
- При первом же положительном `attempts = 0`.

### Проверки

| Вход | Ожидание | Факт |
|---|---|---|
| 0, −2, 3 | Квадрат 9, отклонено 2 |совпало |
| 5 | Квадрат 25, отклонено 0 | совпало|
| −1, −1, −1, 1 | Квадрат 1, отклонено 3 | совпало|
| 100 | Квадрат 10000, отклонено 0 |совпало |

## 4. variant.py — Вариант 14: числа, кратные 5

### Логика
- `value % 5 == 0` — условие кратности. Ноль тоже подходит.
- Список не используется: считаем и суммируем на лету.

### Проверки

|---|---|---|
| n=7: −12, −3, 0, 2, 10, 15, 20 | Количество 4, сумма 45 | совпало|

| n=3: 1, 2, 3 | Количество 0, сумма 0 |совпало |
| n=5: −10, −5, 0, 5, 10 | Количество 5, сумма 0 |совпало |
| n=4: 5, 10, 15, 20 | Количество 4, сумма 50 | совпало|
